# Changelog

All notable changes are listed here. The format follows Keep a Changelog and the project follows semantic versioning.

## [0.5.0] - 2026-11-24

### Added
- Grok as a fourth AI engine.
- Actions on several selected lines at once; columns by dragging a line beside another.

### Changed
- New name, **NøteCraft**, and a new logo. The command is `notecraft`; the data and settings folders carry the new name.
- Interface improvements and fixes.

### Removed
- The sample workspace and the import of one specific application's exports.

## [0.4.0] - 2026-11-24

### Added
- Dashboard and graph views; more diagram types; export as a website.
- Meetings: speakers told apart and renamed, custom vocabulary, a faster second speech engine.
- ChatGPT as a third AI engine.
- Import check (`notecraft verify`); more property types and nested filters.

### Changed
- Interface improvements and fixes.

### Security
- Assistant file tools refuse sensitive files by default and can be limited to chosen folders.

## [0.3.0] - 2026-11-23

### Added
- Import from Evernote, Obsidian, Bear, Joplin, Word, HTML, CSV and Markdown.
- Tabs, presentation mode and reminders.
- Formula and rollup properties; chart and timeline views; table, bookmark, equation and diagram blocks.
- Meetings can record what the Mac plays, with or without the microphone.

### Changed
- New app icon; calmer interface.

### Security
- Links and exports are restricted to the workspace.

## [0.2.0] - 2026-11-23

### Added
- Meeting notes: local transcription, note templates and microphone selection.

## [0.1.0] - 2026-11-22

First release.

- Pages inside pages and a block editor; links and backlinks.
- Databases with five views.
- Search, attachments, import and export (Markdown, HTML, PDF, Word).
- Private pages, automatic backups and version history.
- Local AI (Ollama) or Claude, and an MCP server for assistants.
- Light and dark appearance, English and French.
